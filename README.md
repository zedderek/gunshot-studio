# GUNSHOT.STUDIO

The source for [gunshot.studio](https://gunshot.studio), an interactive audiovisual archive for GUNSHOT.

## Project structure

- `index.html` — website interface, styles, and behavior
- `assets/` — production logo and archive media
- `assets/archive/` — photographs and artwork
- `PROJECT_NOTES.md` — infrastructure and content-workflow notes

## Hosting

- Website: Netlify
- Domain and DNS: Cloudflare
- Music: SoundCloud
