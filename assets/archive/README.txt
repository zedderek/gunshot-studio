GUNSHOT IMAGE ARCHIVE

1. Copy your JPG, PNG, AVIF, or WebP files into this folder.
2. Open index.html in a text editor.
3. Find: const ARCHIVE_IMAGES = [
4. Add one line per image:

   { title: "WORK TITLE / 007", src: "assets/archive/your-file.jpg" },

Recommended export:
- JPG or WebP for photographs
- 1600-2400 pixels on the longest edge
- sRGB color
- Under 1.5 MB per image when possible
- Use lowercase filenames without spaces, for example: red-room-01.webp

The order in ARCHIVE_IMAGES controls the order shown on the website.
